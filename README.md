# hxwl-03 岩土钻孔编录

钻孔分层、标准贯入试验与地下水位的现场记录闭环：分层自孔口连续至孔底，标贯试验段落层校验，水位以下松散砂层强制护壁，冻结后仅可留痕修订。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 业务闭环规则

1. **分层连续**：每孔分层从孔口（0m）连续到孔底。层顶深度自动等于上层层底，末层层底恒等于孔深（随孔深修改自动同步），结构上杜绝断档与超深；`validateLayers` 在冻结前再做一次全量校验。
2. **标贯落层**：标贯试验段为顶深起 0.45m，必须完整落在单一土层内。跨越分层时阻止提交，并在错误信息中列出被跨越的相邻层（层号、岩性、深度区间）；已录入的标贯在分层调整后会被实时重校验并标红。
3. **水位与护壁**：地下水位埋深首次录入后，水位以下的松散砂层（岩性含“砂”且密实度为“松散”）必须记录护壁方式；缺失时冻结清单对应项不通过，整孔不得冻结。
4. **冻结与修订**：校验全部通过方可冻结；已冻结钻孔只读，只能“新建修订”——填写必填原因后，修订前的旧值（孔深、水位、全部分层与标贯）存入修订链快照并解锁编辑，重新冻结完成闭环。

## 数据落盘

- 全部钻孔数据（分层、标贯、水位、状态、修订链）实时写入浏览器 `localStorage`（键：`hxwl03.boreholes.v1`），刷新后状态一致。
- 侧栏“导出 JSON”可下载全量数据存档；“恢复示例数据”可重置。

## 代码结构

- `src/domain.ts` —— 领域模型与四条规则的纯函数校验（连续性、落层、护壁、冻结清单、快照）
- `src/storage.ts` —— localStorage 读写、示例数据（含一个已冻结且带修订链的钻孔 ZK-21）
- `src/App.tsx` —— 钻孔列表、编辑器（基本属性 / 冻结与修订 / 分层 / 标贯 / 修订链）
- `verify-rules.ts` —— 规则闭环验证脚本
